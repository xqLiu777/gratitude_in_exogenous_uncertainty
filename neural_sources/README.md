# Neural/RSA source package

This folder contains the non-backup neural-analysis sources found under `CMF2024`:

- `CMF2024/fmri/03_rsa/`: within-subject RSA notebooks, derived CSV/XLSX results, figure-source files and condition information;
- `CMF2024/fmri/others/fmri_regressor_rsa/`: RSA-regressor Rmd, behavioral model inputs and derived fit/test tables;
- `CMF2024/fmri/04_mvpa/`: current MVPA notebooks and available derived results;
- `CMF2024/fmri/06_decoding/`: current decoding notebook, ROI outputs and decoder data.

The large NIfTI image collections and backup/checkpoint folders were not copied. They remain in the original `E:\lxq\jupyter\LeoResearch\CMF2024` tree. CSV/XLSX statistical results and result figures are retained here; other neural data objects were excluded. Therefore these sources document the analysis and preserve the requested derived results, but the full raw-image rerun requires the original NIfTI inputs or a separately deposited imaging dataset.

The original CMF2024 files were not modified or moved.
