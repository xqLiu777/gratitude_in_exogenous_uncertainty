# Computational Resilience in Human Reciprocity

This repository contains the analysis materials for *Computational Resilience in Human Reciprocity: Asymmetric Intrinsic Prosocial Bias Sustains Cooperation under Exogenous Uncertainty*. Across eight experiments, we show that people adjust gratitude and reciprocity asymmetrically when uncertain outcomes become known: positive deviations increase reciprocity, whereas unintended shortfalls produce relatively little reduction. Behavioral experiments, computational model comparison, fMRI MVPA/RSA, and third-party social evaluations converge on an asymmetric intrinsic prosocial bias that helps sustain cooperation under environmental uncertainty.

The package includes behavioral analyses, model code and inputs, neural-analysis code, processed neural summaries, manuscript figures, and a result-to-code/data map. Raw and intermediate NIfTI files are not included. MRI first-level data: [Figshare record](https://figshare.com/s/4fa1de0f98549ad95bdc).
