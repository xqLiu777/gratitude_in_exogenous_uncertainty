# Running the retained model scripts

Run these scripts with the working directory set to this folder. Model inputs are in `01_data/`, the included core Experiment 3 fit object is in `02_results/`, and figures are written to `04_pic/`.

The model-comparison scripts can run from the included `model_result_260413.xlsx`. The PPC and subject-parameter plotting scripts can run from the included `model_ascertain_EXP3_2_output_260410.Rdata` after the required R packages are installed.

The package does not contain every historical model fit object. The full parameter-recovery Rmd can generate the missing fits, but reproducing every historical model version requires the remaining large fit-object set from the original research directory.
